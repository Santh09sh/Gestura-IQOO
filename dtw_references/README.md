# DTW Reference Templates
# This directory holds recorded hand landmark sequences for DTW matching.
# Each file is a JSON file: {"sign": "sign_name", "landmarks": [...]}
# Record references using the phone UI's "Record Reference" mode
# or by manually creating JSON files.
#
# Naming convention: {sign_name}_{nn}.json (e.g., hello_01.json)
# Multiple templates per sign are supported and recommended (3+ per sign).
